# Host 目录 WS 修复与镜像同步（2026-10-26）

## 根因与修复范围

Lead 已提供真实网关对照：浏览器、Python websockets 和 ws 能完成目录查询；Node 22 内置 undici WebSocket 在 open 后无关闭帧断开，关闭码 1006。桌面画面由浏览器连接，不受 Host 目录查询实现选择影响。

本方检查冻结的 0.1.4 Runtime（sha256:054a7d9b…）内 `/opt/agentkit/personal-assistant/plugin/src/host-gateway.mjs`，确认仍为 `WebSocketImpl = globalThis.WebSocket`。本地插件此前已修复，镜像内的旧源码没有同步，不能把本地包的验证当作镜像已修复。

本轮保留 DSH Host 依赖优先，依次从 Host 入口、插件包及其上级、云端固定安装目录解析 ws；仅均不可用才回退 globalThis.WebSocket。解析在模块加载时完成，仍允许测试注入实现。没有全局替换浏览器 WebSocket，也没有增加网络/鉴权绕过。

目录关闭错误新增数值 closeCode，RPC 和客户端诊断保留该字段。1008 仍为 403，不按临时目录故障处理；不复制远端 reason，以免其中含票据或内部信息。诊断默认折叠，刷新成功后清除。

首帧 12 秒截止已在本地客户端源码和打包产物中实现。更新云端 Runtime 不会替换用户本地 dist/client.js；安装完整新插件包并重开 Host 才能同时加载这些 Host/client 改动。安装和用户 App/profile 仍由 Lead 负责。
