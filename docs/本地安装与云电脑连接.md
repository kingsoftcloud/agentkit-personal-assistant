# 本地安装与云电脑连接

个人助理面板属于本插件。Studio 只提供 DSH 宿主和插件中心；启用后会在侧栏出现 Personal Assistant，首次打开不会自动连接云电脑。

## 安装包

在项目目录执行 `npm run build:client && npm pack`，得到 `kingsoftcloud-agentkit-personal-assistant-0.1.0.tgz`。包内包括可直接由 DSH ModuleLoader 加载的 `dist/client.js`、Host 代码和中文文档。在 Studio「插件」的安装来源输入框填写本地 tarball 的绝对路径；当前入口不是文件上传。已经安装当前版本时只需启用该 bundle，无需访问内网 npm registry。离线升级应先备份 profile，只替换对应包的内容，复用现有依赖，避免重新安装整个 profile 时解析内网包。

## 配置 Host

在启动 Studio 的环境中设置以下变量，或将对应的 `gatewayUrl`、`agentId`、`apiKey` 写入个人助理插件的 Host 配置：

| 环境变量 | 含义 |
| --- | --- |
| `AGENTKIT_PERSONAL_ASSISTANT_GATEWAY_URL` | 可信云网关的 origin，例如 `https://gateway.example/`；不能包含 API 前缀、查询参数或凭据 |
| `AGENTKIT_PERSONAL_ASSISTANT_AGENT_ID` | 已创建的真实 Agent ID；不能填写本地 profile 名称 |
| `AGENTKIT_PERSONAL_ASSISTANT_GATEWAY_API_KEY` | 云网关 API Key，仅由 Host 读取，不传给浏览器 |
| `AGENTKIT_PERSONAL_ASSISTANT_ALLOW_HTTP_GATEWAY` | 仅预发 HTTP 网关需要显式设置为 `1`；生产使用 HTTPS |

未配置时，面板显示「云网关未配置」，其余 Studio 功能可继续使用。当前云端尚未提供 Bot 目录查询，页面会明确提示手动填写已经存在的 Bot ID，不会生成虚假的默认 Bot。

## 使用

填写 Bot ID，选择「连接 / 重试」申请控制，或选择「只读旁观」。其他 Bot 持有控制租约时，服务端返回 409，面板进入只读状态并显示橙色横幅。只有持有租约的 Bot 可以输入；只读限制也由服务端校验。

浏览器通过 `connection.rpc.call('/api', 'personal-assistant', { operation, payload })` 发送标准 Connection RPC envelope。Host 在现有 `connection.fetch.register` 的 `/api/personal-assistant` 精确注册表中处理它，再向云网关请求 `IssuePersonalAssistantDesktopTicket`。该公共契约已在本地 DSH `0.2.1-rc.2` 实测：`packages/client/connection/src/rpc-host.ts` 的 `createSharedFetchHandler` 先验证 owner Peer 再分发精确路径，`registerFetchRoute` 负责生命周期清理。它不是 manifest 的 contributes 元数据，也不新增 HTTP 服务或占用 Gateway interceptor。

Host 只接受 POST JSON、16 KiB 以内的请求和配置查询、Bot 目录状态、桌面 ticket 三种操作，保留 Connection 的 Host/Origin 与浏览器会话鉴权；请求取消会传给云网关。当前宿主的独立 `rpc.handle` 通道存在 Cordis getter 上下文问题，因此不使用该路径，更不绕过宿主校验。

浏览器只得到短时一次性 ticket。桌面连接固定为同一网关 origin 下的 `/personal-assistant/desktop/ws`，使用 `agentkit.personal-assistant.desktop.v1` 子协议和 ticket 子协议，不在 URL query 携带 token。帧通过独立 WebSocket 二进制 JPEG 传输，不占用 DSH remotes 事件通道，不落盘也不进入遥测。

鼠标坐标按桌面原始比例映射，留黑边时不会拉伸。文本通过输入与 IME 组合事件发送；Ctrl/Cmd/Alt 等组合键保留按下、抬起顺序。关闭面板会关闭桌面连接并释放租约；页面隐藏时暂停画面，恢复后重新接收。网络中断后会重新获取 ticket 并连接，超过五次重试后显示明确错误。

本地插件安装与页面加载不代表云端桌面验收通过。真实 Pod 的 AppArmor、帧率、输入延迟、中文回显和多 Bot 冲突证据，按 `desktop-view-acceptance.md` 单独记录。
