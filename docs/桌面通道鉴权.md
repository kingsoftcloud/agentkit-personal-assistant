# 云电脑桌面通道鉴权

浏览器不持有 Runtime token，也不把凭据放到 URL。用户先通过既有 Server 鉴权申请 30 秒有效的一次性 ticket；Gateway 用 Redis 原子消费 ticket 后，取得 Server 签名的桌面 permit，再连接 Runtime WebSocket。

## 受信配置

Runtime 从平台环境读取以下二选一配置，不能从入站请求头选择验证密钥：

- `AGENTKIT_DESKTOP_JWKS_URL`：现有 Server 公钥端点 `/agentengine/api/v1/agent-control/jwks` 的完整 HTTPS URL。
- `AGENTKIT_DESKTOP_JWKS_JSON`：平台注入的完整 `{ "keys": [...] }` 公钥文档。

预发使用 HTTP 公钥地址时，平台必须显式注入 `AGENTKIT_DESKTOP_ALLOW_HTTP_JWKS=1`。未配置公钥、验签失败、permit 过期或 Agent 不匹配，Runtime 均拒绝握手。

## 授权与协议

permit 是 EdDSA JWS，复用 Server 现有 AgentControl workload Ed25519 密钥。固定 `iss=agentengine-server`、`aud=agentkit-personal-assistant-desktop`、`scope=desktop`，绑定 Agent、账号、用户、Bot、read/control、可选 lease、签发时间、最长 60 秒有效期和唯一 nonce。

Gateway 只传签名 permit。Runtime 不信任“非空即有效”的身份头，不能通过修改 WebSocket open 消息，把只读 permit 改成控制或换成另一 Bot。Bot 不匹配返回 403，只读请求控制返回 409；同一 permit nonce 不能在当前 Runtime 再开连接。WebSocket 协议统一为 `agentkit.personal-assistant.desktop.v1`。

仅 loopback 工具调用可以使用用户专属 Runtime Bearer token。公网桌面连接必须使用 permit。

## 租约与帧

broker 对 action、桌面输入、renew、release 同时核对 Bot、task、leaseId 和用户/电脑身份。控制连接每 30 秒续约，断开时释放自动取得的租约；过期租约会关闭对应桌面会话。只读连接可以看帧，不能输入。

broker 的桌面实时路径直接返回 JPEG Buffer，Runtime 以 WebSocket 二进制帧传输，不做 JPEG 的 base64 往返，不写磁盘。JSON 截图接口只保留兼容用途，不参与实时 WebSocket 路径。

这些契约测试不替代真实 Gateway、Pod AppArmor、Studio 面板操作与帧率验收。
