## 用户确认的产品形态

一个已认证子账号对应一个个人助理 Agent、一个用户 Pod、两个容器。唯一约束仅用于 `personal-assistant`，普通 Agent 的创建不受影响。多逻辑 Bot 保留为内部能力，用户页面不提供“个人助理/研究助理”分类、Bot ID 或实例关联选择器。

聊天由该 Agent 的云端 DSH 执行，云电脑绑定同一 Agent/Bot。云端不可用时显示具体错误，禁止静默回退到本地执行。Studio 保留通用宿主能力，个人助理产品由独立插件承接。

云电脑放入真正的 DSH 右侧栏，使用原生标签、宽度调整、全屏与 Esc。页面使用浅色外层、等比圆角桌面卡片和紧邻画面的控制提示；整幅桌面保持比例。点击画面接管并重放第一次点击，点击画面外释放控制并继续旁观。

本轮已加入真实底栏：浏览器、终端、文件。文件入口打开 Thunar，默认目录为共享云盘上的 `/workspace`。浏览器入口聚焦或恢复 Computer 管理的同一 Chromium、私有 profile 和 CDP；浏览器进程恢复沿用持久资料目录。底栏是云电脑内真实应用入口。

### “只显示一半”与关闭标签的核验

“只显示一半”的本轮根因是测试设置：主任务固定了 Playwright `viewport=1920×964`，而实际外层窗口只有 `1201×906`，导致测试内容视口大于用户看见的窗口。改用自然窗口 `viewport:null` 后，实际内容区为 `1467×862`，外层窗口为 `1467×949`，页面已适配。此处修正的是测试窗口设置，不将它记为产品代码修复。

自然窗口中再次关闭右侧云电脑标签，前后 `performance.timeOrigin` 相同，个人助理主页面始终存在，右侧桌面视图消失。该证据排除了“关闭右侧标签本身导航到 Home”的推断。原件：`.artifacts/desktop-handoff-20261026/preprod/natural-window-close-proof.log`，截图 `output/playwright/chat-natural-after-computer-close.png`。

Studio 通用页面恢复原来只检查内置列表，因此保存 `personal-assistant` 后刷新会落到 Home；修前原件为 `.artifacts/desktop-handoff-20261026/preprod/reload-before-generic-fix.log`。Studio `51bb1b9` 改为等待真实注册的主页面，保留注册校验，并允许用户新导航取消恢复，没有加入个人助理专属页面或硬编码例外。修后 `.artifacts/desktop-handoff-20261026/preprod/exact-package-refresh-proof.log` 已验证：刷新前、后都为个人助理，保存的页面 ID 保持一致；自然窗口下输入框完整可见。

通过真实 Studio 页面再次输入 100 个 ASCII 和 50 个中文字符，Pod 文件 `/workspace/pa-e2e/PANEL_016_100ASCII_50CJK.txt` 精确为 252 字节；证据 `.artifacts/desktop-handoff-20261026/preprod/studio-016-input-bytes.json`。另有中文、英文和 emoji 的页面回显截图。
