## 用户确认的产品形态

一个已认证子账号对应一个个人助理 Agent、一个用户 Pod、两个容器。唯一约束仅用于 `personal-assistant`，普通 Agent 的创建不受影响。多逻辑 Bot 留作内部能力，用户页面不提供“个人助理/研究助理”分类、Bot ID 或实例关联选择器。

聊天由该 Agent 的云端 DSH 执行，云电脑绑定同一 Agent/Bot。云端不可用时显示错误，不能静默改成本地执行。Studio 保留通用宿主能力，个人助理产品由独立插件承接。

云电脑进入真正的 DSH 右侧栏，使用原生标签、调整宽度、全屏与 Esc；插件不创建另一套窗口布局或本地执行会话。新展示使用跟随主题的外层、等比圆角桌面卡片和紧邻画面的控制提示，保留整幅桌面，不拉伸、不裁切。点击画面接管并重放第一次点击，点击画面外释放控制并继续旁观。

本轮补齐真实文件管理器和底栏入口：浏览器、终端、文件。文件管理器默认打开云电脑 `/workspace`。浏览器入口必须恢复或聚焦 Computer 管理的同一 Chromium/profile/CDP，不能偷偷另起一个浏览器。文件管理器不是浏览器中的静态文件列表。
