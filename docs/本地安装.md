# 本地安装 Personal Assistant 插件

## 当前状态

Personal Assistant 是独立的 DSH 插件。插件本身默认关闭、不会自动连接云电脑；Studio 只负责插件中心和通用宿主，云端回合由个人助理 runtime 镜像中的独立 DSH Host 承载。

## 安装插件包

在本机没有内网 npm registry 时，使用本地 tarball：

```sh
npm install --prefix "$HOME/.dsh/profiles/<profile>" \
  /绝对路径/kingsoftcloud-agentkit-personal-assistant-0.1.0.tgz
```

如果该 bundle 已经存在于 profile，Studio 插件中心会直接调用 DSH 的 `setBundleEnabled`；不会再次把包名交给 registry 解析。

## 安装 Studio bundle

需要先使用包含 `src/dsh-plugin-catalog.mjs` 的 Studio bundle。安装后重新启动 Studio，在插件中心可以看到“Personal Assistant”，初始状态为“已安装、未启用”。点击启用才会加载插件；旧个人助理数据目录不由插件安装过程删除。

## 验证

```sh
dsh --profile <profile> --dump-config
```

输出中应包含：

```yaml
- id: personal-assistant
  name: '@kingsoftcloud/agentkit-personal-assistant'
```

云电脑镜像内置 Python、Bash/shell、Git、OpenSSH、Chromium 和 skill 执行能力，本期不提供这些能力的开关。
