本次默认模型固定为用户指定的 `deepseek-v4.1-flash-1017`。新建请求示例使用这个名称；显式指定其他模型时仍尊重 Manifest。Manifest 中的模型与身份校验继续保留。其他 Agent 的默认模型不在本次修改范围内。

## 实现

命令公网默认可用，没有网络开关、域名白名单或域名审批。命令与云电脑控制服务仍分离：程序通过普通 DNS、TCP/UDP 访问公网；不能绕过租约直连 X11、Broker、云元数据或宿主凭据。匿名 Unix socketpair 用于 curl/Git DNS 线程；命名 Unix socket 仍拒绝。网络系统调用由代理固定 FD、复制目的地址后执行，不能用并发参数替换改变授权目标。保留 Landlock、元数据写入代理与命令超时，不再选择离线 bwrap 作为生产兜底。

`cloud_browser_press`、`cloud_browser_download` 补齐原有协议漏项。`cloud_computer` 增加整屏截图、坐标点击/双击/右键、文本、组合键、滚轮、拖拽、窗口枚举/聚焦、浏览器/终端/文件管理器入口。所有动作到同一台 Computer，经同一个 Bot 租约；用户接管后旧输入由服务端拒绝。尚未取得租约时可等待用户交还，不重放结果未知的动作。

截图经 DSH 附件服务作为真正的图像内容送入模型。默认模型声明 text/image 输入；其他未经验证的模型只声明 text，截图前明确拒绝，不能用文件路径冒充模型已看图。

`cloud_workspace` 提供受沙箱约束的文件读写、列表和技能发现；技能执行继续使用同一 `cloud_bash`。`assistant_schedule` 连接持久化云端调度器，可创建、列出和取消一次性任务，Bot 归属由闭包固定，任务时间必须含时区。运行中的任务不能伪报已取消。

插件会话支持每个最多 512 KiB、每条消息最多四个附件。文件直接落到对应云电脑工作区；图片可进入模型附件通道。生成文件可用 `[下载文件](cloud-file:URL编码后的工作区相对路径)` 交付，下载上限同为 512 KiB。文件访问逐级固定目录 FD 并拒绝符号链接，不能读取 Runtime 私有目录。桌面实时帧不走文件交付通道。

聊天页“云电脑”入口增加图标与边框，关闭侧栏后仍可从此处重开。处理中展示真实 DSH 工具事件的简短进度，不读取工具参数或把模型思考过程当作进度。
