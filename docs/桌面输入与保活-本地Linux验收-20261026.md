## 控制权补强与回归

`desktop-session.test.mjs` 与 `cloud-browser-lifecycle.test.mjs` 合计 **37/37** 通过。除输入、字体与保活外，还覆盖：

- 同一观察会话切换控制权，清理按住的键/鼠标；旧租约代次不能借新控制权执行。
- CDP down ACK 迟到时仍可先发匹配 up，清理失败必须阻止授予控制权。
- 工具关闭浏览器时，每个关闭/进程回收步骤都检查权限；接管后旧回合不能继续关闭或杀掉浏览器。
- 正在关闭或已人工关闭的页面，在同一 Chromium 上恢复目标；旧 close ACK 迟到不能清除替代页面。
- 未知 CDP 网络错误不能伪装成“页面不存在”而静默重建。

真实 HTTP Broker + EdDSA 票据 + CDP 故障注入复现中，旧 stop/click 均在接管后返回 409；清理 mouseReleased 发生在授予人类控制权之前。该故障注入结论与真实 Linux 的输入/窗口证据分别记录，不能互相替代。
