# 长命令取消与公网依赖（2026-10-27）

## 发现

0.1.21 预发真实回合中，Python 和 Node 的公网 HTTPS 返回 200，SSH 在 `ssh.github.com:443` 完成主机密钥握手；GitHub 当前一次解析到的 `20.205.243.166:443` TCP 连接超时，不能把 Git 记为本轮通过，也不应固定 IP 或关闭 TLS。完整工具结果在 `cloud-network-turn-021.log` 和 `network-021-tool-results.log`，失败保留。

另一个真实代码问题是 Broker HTTP transport 固定 30 秒，而 `cloud_bash` 已允许 120 秒默认、300 秒上限。原先会在命令仍执行时先断 RPC，且没有把取消传到 Computer 进程组。

## 修复

- Broker 为 `terminal.exec` 按已校验的 `timeoutMs` 留出执行期限和 5 秒回传余量，普通状态请求仍使用短超时。
- 新增严格的 `computer.lease.renew` 协议；租约续期必须匹配原 Agent、Bot、任务、Computer 和 leaseId，不能借其他 Bot 延长。工具在执行期间按租约三分之一心跳续租，动作结束清理心跳。
- Computer 记录每个 Agent lease 的执行 AbortController。用户接管、租约释放、过期、请求断开和进程关闭都会终止关联进程组；结果未知时返回可识别错误，不自动重放。
- 新增 17 个单测覆盖 30 秒与 120 秒边界、响应取消、同租约续期、真人接管、请求断开和无请求过期。当前 PA 检查 250 通过、2 个目标 Linux 专项跳过、0 失败。

## 镜像依赖

Computer 镜像新增固定版本：`curl=7.88.1-10+deb12u15`、`python3-pip=23.0.1+dfsg-1`、`python3-venv=3.11.2-1+b1`。构建期执行 `curl --version`、`pip --version` 和 venv 创建检查，版本同步写入 `sources.lock.json` 与静态镜像门。

公网仍是默认能力，工作区、凭据、回环 Broker、内网/元数据和命令沙箱边界保持不变。`pip` 安装不写系统目录，应在工作区 venv 中执行。
